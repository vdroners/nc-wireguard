- **WireGuard** — registered trademark of Jason A. Donenfeld. This app is **not** affiliated with or endorsed by the WireGuard project.
- **wg-easy** — third-party web UI for WireGuard; this app polls its API. Not affiliated with or endorsed by wg-easy.

## GeoIP (optional, off by default)

When enabled, peer public IP addresses may be sent to:

- **ip-api.com** free tier — HTTP only, [non-commercial use](http://ip-api.com/docs/legal), attribution required; or
- **ip-api Pro** — HTTPS with operator-supplied API key; or
- **Custom endpoint** — operator-provided URL template.

## Map tiles

The Map tab may load basemap tiles from **CARTO** / **OpenStreetMap** contributors. Follow their respective licence and attribution requirements when GeoIP/map features are used.
